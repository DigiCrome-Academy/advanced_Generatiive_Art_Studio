# Generative Art Studio

Generative Art Studio is a creative workspace for exploring algorithmic and AI-driven art.

Key features:
- Generate visuals using code, models, and procedural systems
- Experiment with shapes, colors, textures, and movement
- Combine user input with automated design rules
- Export artworks for sharing and iteration

This studio is ideal for artists, designers, and developers who want to build expressive, generative art projects.
